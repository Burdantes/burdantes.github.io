# Syntax cheatsheet (al-folio demo posts)

These are the al-folio theme's demonstration posts. They are **not published** —
Jekyll ignores `_drafts/` in a production build — but they are kept here as a
reference for post syntax. To see one rendered, run `bundle exec jekyll serve --drafts`.

| File | Demonstrates |
|---|---|
| `2015-03-15-formatting-and-links.md` | Markdown basics, footnotes, blockquotes, links |
| `2015-05-15-images.md` | Responsive figures, image grids, `figure.liquid` include |
| `2015-07-15-code.md` | Fenced code blocks, syntax highlighting, line numbers |
| `2015-10-20-math.md` | Inline and display MathJax, numbered equations |
| `2015-10-20-disqus-comments.md` | Disqus comments (deprecated — this site uses giscus) |
| `2018-12-22-distill.md` | `distill` layout: sidenotes, citations, two-column asides |
| `2020-09-28-github-metadata.md` | Pulling GitHub repo metadata into a post |
| `2020-09-28-twitter.md` | Embedding tweets/timelines |
| `2021-07-04-diagrams.md` | Mermaid, Vega-Lite, TikZ via `jekyll-diagrams` |
| `2022-02-01-redirect.md` | `redirect:` front matter for link-only posts |
| `2022-12-10-giscus-comments.md` | giscus comments (what this site uses) |
| `2023-03-20-table-of-contents.md` | In-body table of contents |
| `2023-03-21-tables.md` | Markdown and HTML tables, sortable tables |
| `2023-04-24-videos.md` | Local and embedded video |
| `2023-04-25-audios.md` | Audio embeds |
| `2023-04-25-sidebar-table-of-contents.md` | Sticky sidebar TOC (`toc: sidebar: left`) |
| `2023-05-12-custom-blockquotes.md` | Callout / tip / warning blockquotes |
| `2023-07-04-jupyter-notebook.md` | Embedding a `.ipynb` from `assets/jupyter/` |
| `2023-07-12-post-bibliography.md` | Per-post bibliography via jekyll-scholar |
